The sedan is a modified, unbranded standard 2019 G20 mesh, derived from
LePoint_BAT's model obtained from:
https://downloadfree3d.com/3d-models/vehicles/car/bmw-3-series-g20-2019/

The source archive did not include a public license. The project owner confirmed
permission to redistribute this asset on 2026-11-16. This asset is excluded from
the repository code's MIT license; that permission does not relicense the original
model under MIT.

All badges, plate lettering, model lettering, wheel emblems, tire lettering and
branded brake faces were removed. There are no image textures. The road mesh
shares the approved model's body and glazing, with simplified small trim details:
38,156 vertices and 61,452 triangles. The blue ego vehicle and graphite traffic
share geometry. Vehicle appearance is illustrative; metadata does not identify
the actual make or model.

Three.js 0.170.0 and RoomEnvironment are vendored under vendor/three/LICENSE (MIT).

`home-driving.webp` is a static render of the same approved model geometry with
synthetic lane positions. It contains no personal recording or route data and
is covered by the same asset permission as the source mesh.

`dashboard-sedan.webp` is a transparent render of the same approved unbranded mesh for the dashboard.

Driving View uses sedan-replay.bin.gz, a reduced-detail version of the same
approved geometry with 8,577 triangles. It retains the original materials.
